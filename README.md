# Level Wiki

같은 개념을 다섯 단계 난이도로 읽는 사이트. 슬라이더를 올리면 설명이 **교체되지 않고 자랍니다.**
비유가 빠지고 수식이 들어오는 식으로 블록이 등장·퇴장하기 때문에, 읽는 사람이
자기 이해가 어디서 끊기는지 스스로 보게 되는 것이 목적입니다.

```bash
npm run dev
```

- `npm run dev` — 개발 서버 (http://localhost:4321)
- `npm run build` — 정적 빌드 (`dist/`)
- `npm run validate` — 콘텐츠 무결성 검사

## 구조

```

  lib/

    content.ts              문서 로딩, slug 해석

    graph.ts                선수 관계 그래프 배치 계산

    SaveButton.tsx          내 지식에 저장

  pages/

    c/[slug].astro          개념 페이지
    f/[field].astro         분야 목록
    p/[slug].astro          현상 페이지
```

본문은 정적 생성되어 검색엔진에 그대로 노출되고, 슬라이더 부분만 클라이언트에서 살아 움직입니다.
JS가 없어도 L1 내용은 정상적으로 읽힙니다.

## 레벨

| 레벨 | 라벨 | 성격 |
|---|---|---|
| 1 | 감만 잡기 | 비유만, 수식 없음 |
| 2 | 교과서 | 정의와 대표 예시 |
| 3 | 전공 입문 | 수식과 성립 조건 |
| 4 | 전공 심화 | 유도 과정과 예외 |
| 5 | 연구자 | 미해결 쟁점 |

학년이 아니라 목적으로 라벨을 붙였습니다. 학년으로 쓰면 사람들이 자존심 때문에
필요보다 높은 레벨에 머물러, 정작 이 사이트가 알려주려는 것을 못 보게 됩니다.

## 블록

문서는 통짜 글이 아니라 블록의 배열입니다. 블록마다 등장 구간이 정해져 있고,
슬라이더를 움직이면 그 구간에 따라 열리고 닫힙니다.

| 블록 | 기본 구간 | 화면 표시 |
|---|---|---|
| `oneline` | 1–5 | 제목 없이 강조 박스 |
| `analogy` | 1–3 | 비유 |
| `core` | 1–5 | 핵심 |
| `math` | 3–5 | 수식 |
| `misconception` | 2–5 | 흔한 오해 |
| `application` | 2–5 | 어디에 쓰이나 |
| `frontier` | 5 | 아직 안 풀린 문제 |

문서에서 `minLevel` / `maxLevel`로 구간을 덮어쓸 수 있습니다.

## 문서 작성

```json
{
  "slug": "entropy",
  "title": "엔트로피",
  "field": "thermodynamics",
  "summary": "목록 카드에 쓰는 한 줄. 항상 L1 톤으로.",
  "prereq": ["temperature"],
  "next": ["gibbs-free-energy"],
  "terms": {
    "미시상태": { "brief": "툴팁에 뜰 한 줄 설명", "slug": "선택: 독립 문서가 있으면" }
  },
  "blocks": [
    { "type": "oneline", "byLevel": { "1": "...", "3": "..." } },
    { "type": "math", "minLevel": 3, "byLevel": { "3": "..." } }
  ]
}
```

**`byLevel`은 모든 레벨을 채우지 않아도 됩니다.** 비어 있는 레벨은 바로 아래 레벨 원고를
그대로 씁니다. 위 예시의 `oneline`은 L1·L2에 첫 글, L3·L4·L5에 둘째 글이 뜹니다.
이 fallback 덕분에 집필량이 레벨 수만큼 배가되지 않습니다.

### 본문 인라인 문법

| 문법 | 결과 |
|---|---|
| `$...$` | 인라인 수식 (KaTeX) |
| `$$...$$` | 블록 수식 — 한 문단을 통째로 차지하게 두면 가장 깔끔합니다 |
| `[[용어]]` | 점선 밑줄 + 툴팁. `terms`에 등록된 것만 |
| `**강조**` | 굵게 |

문단은 빈 줄(`\n\n`)로 나눕니다.

### 검사

`npm run validate`가 잡아 주는 것:

- 파일명과 `slug` 불일치, 빠진 `oneline` 블록
- 1~5 밖의 레벨 키, `minLevel > maxLevel`
- 등장 구간 밖에 있어 영원히 안 보이는 원고
- `terms`에 없는 `[[용어]]`, 본문에서 안 쓰이는 `terms` 항목
- 짝이 안 맞는 `$`
- 아직 없는 문서를 가리키는 `prereq` / `next` / `terms[].slug`

없는 문서를 가리키는 링크는 **경고**일 뿐 오류가 아닙니다. 집필 중에는 링크가 먼저
앞서 나가기 마련이고, 화면에서는 조용히 빠집니다.

## 도표와 사진

**도표**는 전부 `public/figures/`에 직접 그린 SVG입니다. 본문에 `![캡션](/figures/파일명.svg)`로
넣습니다. 엔트로피나 전기장처럼 사진으로 찍을 수 없는 개념이 대부분이고, 직접 그리면
저작권 걱정 없이 다크모드에도 반응시킬 수 있습니다.

**사진**은 무지개·눈 결정처럼 실물을 봐야 와닿는 것에만 씁니다. 퍼블릭 도메인이거나 CC
라이선스인 자료만 골라 `public/photos/`에 두고, `Phenomenon.hero`에 촬영자·라이선스·원본
주소를 함께 적습니다. **출처 필드는 필수라 빠지면 검증이 실패합니다.**

`sources`에 참고 서적·논문을 넣으면 본문 하단에 작게 뜨고, `minLevel`을 주면 상위
레벨에서만(예: 원 논문은 L4·L5에서만) 노출됩니다.

## 계정과 학습 기록

로그인은 **선택**입니다. 로그인하지 않아도 저장 기능이 그대로 동작하며, 기록은 브라우저
안에만 남습니다. 로그인하면 같은 기록이 계정에 보관되어 다른 기기에서도 이어집니다.

화면은 언제나 `store.ts`(로컬 저장)를 동기적으로 읽어 즉시 그리고, 서버 통신은 뒤에서
일어납니다. 실패해도 사용자가 막히지 않습니다. Supabase SDK는 로그인 흔적이 있을 때만
동적으로 불러오므로, 로그인하지 않은 방문자는 받지 않습니다.

데이터 격리는 애플리케이션이 아니라 **DB의 행 수준 보안**이 강제합니다. 스키마와 정책은
`supabase/migrations/0001_init.sql`에 있습니다. 설정은 `.env.example` 참고.

## 막힘 리포트

`/insights`에서 &lsquo;여기서 막혔어요&rsquo; 기록을 개념·단계별로 모아 봅니다.
링크로 공개하지 않은 운영자 전용 페이지입니다.

RLS는 각자 자기 기록만 보게 막아 두므로, 전체를 집계하려면 별도 장치가 필요합니다.
그래서 `stuck_summary()`라는 Postgres 함수(SECURITY DEFINER)를 두고, 그 함수 안에서
`auth.jwt() ->> 'email'`이 운영자 이메일과 같을 때만 결과를 돌려주게 했습니다. 권한이
없거나 로그인하지 않은 사람에게는 항상 빈 배열이 갑니다 — "운영자가 아니다"를 따로
알려주면 그 자체가 정보 노출이라, 빈 상태와 권한 없음을 화면에서도 구분하지 않습니다.

## 문제 풀기

`/quiz`에서 저장한 개념 중 문제가 준비된 것을 골라 5문항을 풉니다. 문제는 AI로
실시간 생성하지 않고 `src/content/quiz/*.json`에 **미리 써 둡니다.** 그래서 서버도
API 키도 필요 없고, 사이트는 100% 정적으로 남습니다. 채점은 브라우저에서 즉시
끝나며, 결과는 `user_concepts.understanding`에 개념별 이해도로 남습니다.

출제는 **읽은 단계 이하**로 제한됩니다 — 3단계까지 읽은 사람에게 5단계 문제를
내면 시험이 아니라 함정이기 때문입니다. 오답 보기는 개념 문서의 "흔한 오해"
블록에서 끌어옵니다. 자세한 형식과 설계 근거는 `docs/phase6-quiz.md`에 있습니다.

## 남은 일

- **문제 문항 늘리기.** 개념 53개 + 현상 7개, 모두 5문항씩 채웠습니다(300문항).
  개념당 5문항이면 두세 번 풀 때 같은 문제가 도니, 자주 푸는 개념부터 10문항
  이상으로 늘리는 것이 좋습니다. 형식은 `docs/phase6-quiz.md` 참고.
- **L4·L5 검수.** 초안을 LLM으로 뽑더라도 이 두 레벨은 직접 확인해야 합니다.
  사이트 신뢰도가 여기서 갈립니다.
- **공유 카드.** 현재는 URL 복사만 됩니다. 레벨이 박힌 이미지 카드를 만들면
  인스타·트위터 유입 경로가 생깁니다.
